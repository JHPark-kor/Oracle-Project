# Reference Reports

이 폴더는 문화누리카드 및 관련 정책 보고서의 위치와 목록을 설명하기 위한 공간입니다. PDF 원본은 용량과 중복 관리를 위해 GitHub에 올리지 않고 로컬 또는 공유 드라이브에서 관리합니다.

중복으로 들어 있던 `Reports/` 폴더는 제거했고, 로컬 원본은 `mnc_package_reports/` 한 곳만 사용합니다.
