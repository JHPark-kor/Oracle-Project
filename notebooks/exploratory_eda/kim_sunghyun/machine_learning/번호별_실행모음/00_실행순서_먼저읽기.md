# 성현 선호도 분석 실행·결과 안내

중복 실행 파일과 바로가기는 제거하고, 팀이 같이 사용하는 정식 노트북만
연결합니다. VS Code에서 필요한 노트북을 열어 **Run All**을 누르면 됩니다.

## 노트북 실행 순서

1. [00 전체 파이프라인](../00_preference_pipeline_run_all.ipynb)
   - 매핑 → 모델 학습·검증 → 격자 인구 정렬 → 지도 → 테스트를 전체 재실행합니다.
2. [01 결과 한눈에 보기](../01_preference_results_overview.ipynb)
   - 재학습 없이 저장된 핵심 결과를 확인합니다.
3. [02 다항 로지스틱 모델 상세](../02_multinomial_preference_model.ipynb)
   - 순위가중치, C·변수구조 선택, 2025년 평가를 확인합니다.
4. [03 공간 적용 상세](../03_spatial_preference_application.ipynb)
   - 100m 격자 잠재수요와 행정동·자치구 집계를 확인합니다.

## 코드와 결과 위치

- 계산 코드: `src/preference_analysis/`
- 자동 테스트: `tests/preference_analysis/`
- 모델 결과: `data/processed/preference_analysis/model/`
- 격자·행정동·자치구 결과: `data/processed/preference_analysis/spatial/`
- 지도: `data/processed/preference_analysis/spatial/maps/`
- [상세 분석 문서](../../../../../docs/preference_analysis.md)

`data/processed` 결과는 Git에 올리지 않으므로 새 clone에서는 `00`을 먼저 실행해야
생성됩니다. 정책 출력은 8개 분야이며 음악 활동코드 76·77은
`기타·문화누리 비대응`으로 통합됩니다.
