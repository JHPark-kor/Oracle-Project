# Notebooks

최종 분석 코드는 주제별 폴더로 나눠 관리합니다. 데이터와 실행 산출물은 Git에 올리지 않고, notebook과 설명 문서만 추적합니다.

| Folder | Description |
| --- | --- |
| `table_design/` | 분석 테이블과 접근성 분석 입력 테이블 생성 |
| `eda/` | 이용 현황, 공급-이용 격차, 상관 분석 등 탐색 분석 |
| `access/` | 접근성 지표, H3SFCA, 취약지수, PCA, 검증 분석 |
| `preference/` | 문화시설 선호 수요 ML 실험 |
| `dashboard/` | 최종 취약지수, 후보지 추천, 취약권역 유형화 |

권장 확인 순서는 `table_design` -> `eda` -> `access` -> `preference` -> `dashboard`입니다.
