## 3. 실패·제외 기록

1. `차상위계층 서울특별시 읍면동` 검색은 결과가 없었다.
2. `국민기초생활보장 수급자 서울 행정동` 검색은 결과가 없었다.
3. `서울 등록장애인 행정동` 검색은 결과가 없었다.
4. `DT_1JC1502`의 제목만 보고 2024 행정동 자료라고 판단하면 오류다.
5. KOSIS 자동 지역 선택 위젯이 선택 상태를 안정적으로 반영하지 않아 범위가 불완전한 XLSX는 저장하지 않았다.
6. 다운로드 대화상자에서 생성된 임시 파일은 데이터 행이 없는 불완전한 OOXML이어서 프로젝트에 포함하지 않았다.

## 4. 재현 가능한 다음 조회 순서

1. KOSIS에서 통계표 ID를 직접 연다.
2. `조회설정`에서 지역·항목·시점을 차례로 선택한다.
3. 셀 수와 실제 지역 수준을 화면에서 확인한다.
4. XLSX로 내려받는다.
5. 메타데이터 시트와 데이터 시트를 모두 보존한다.
6. 지역 열에 서울 행정동 또는 자치구가 실제로 들어 있는지 검증한다.
