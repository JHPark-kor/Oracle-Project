## 전처리 방식

- 기존 `04_disability_elderly_e2sfca.ipynb`는 400m 도보 단독 1차 설계로 보존함.
- 새 설계는 `04_1_disability_elderly_mode_consistent_e2sfca.ipynb`에서 별도로 계산함.
- 도보형 중분류: 도서, 문화체험, 음악, 영상, 체육시설, 체육용품.
- 대중교통형 중분류: 공연, 미술, 스포츠관람, 관광지.
- 장애인친화시설은 `장애인친화시설 == 1`인 가맹점을 사용함.
- 노인편의서비스는 `전화결제 == 1` 또는 `찾아가는문화서비스 == 1`인 가맹점을 사용함.
- 접근성 계산은 중분류별 점수로 나누지 않고, 장애인친화시설 접근성과 노인편의서비스 접근성으로 통합함.
- 도달 가능 중분류와 부족 중분류는 대시보드 원인 설명용 진단값으로 보존함.
- 공급량은 가맹점 1개를 공급 1로 처리함.

## 거리감쇠 방식

- 도보형 중분류: 0~400m는 1.00, 400~750m는 0.50, 750m 초과는 0.
- 대중교통형 중분류: 0~10분은 1.00, 10~15분은 0.50, 15~20분은 0.20, 20분 초과는 0.
- 대중교통 총 접근시간에는 출발 보행, 대중교통 이동, 도착 보행이 이미 포함되어 있음.
- 일반 접근성 분석과 일관성을 유지하기 위해 대중교통 접근성에서 보행감쇠를 추가로 곱하지 않음.
- 최종 통합접근성은 도보 접근성 점수 0.7, 대중교통 접근성 점수 0.3으로 계산함.

## 전처리 특이사항 및 판단

- 기존 400m 도보 단독 설계는 장애인·노인 접근성에서 동점과 접근성 0 격자가 과도하게 발생함.
- 04_1 설계 적용 후 관련 수요 격자 중 접근성 0 비율이 장애인 1.88%, 노인 1.13%로 감소함.
- 장애인친화시설 도달 가능 중분류에서 스포츠관람은 도달 격자가 0으로 나타남.
- 노인편의서비스 도달 가능 중분류에서 스포츠관람과 관광지는 도달 격자가 0으로 나타남.
- 이는 해당 편의 조건을 가진 가맹점 수와 이동수단 기준의 조합이 부족한 결과로 판단함.
- 기존 1차 설계는 한계 설명 및 개선 전후 비교를 위해 삭제하지 않고 보존함.
