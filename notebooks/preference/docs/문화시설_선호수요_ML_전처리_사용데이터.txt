# 문화시설 선호 수요 머신러닝 모델링

## 사용데이터
- `leisure_activity_survey_2021_2025_selected_columns.csv`
  - 국민여가활동조사 2021~2025년 통합 원자료 중 모델링에 필요한 주요 칼럼을 정리한 데이터
  - 주요 칼럼: 조사년도, 성별, 연령, 17개 시도, 지역규모, 최종가중치, 가장 만족스러운 여가활동 1~3순위, 향후 희망 여가활동 1~3순위

- `leisure_activity_survey_2021_2025_selected_columns_enriched.csv`
  - 원자료에 가구소득, 장애여부 등 추가 입력변수를 결합한 모델링용 확장 데이터
  - 주요 칼럼: 성별, 연령, 조사년도, 시도, 장애여부, 가구소득 관련 변수

- `leisure_activity_to_mnc_category_mapping.xlsx`
  - 국민여가활동조사 여가활동 항목을 문화누리 가맹점 중분류 기준으로 매핑한 기준표
  - 문화누리 접근성 분석 대상이 아닌 교통수단, 숙박, 여행사 등은 제외 기준으로 사용

- `leisure_raw_household_income_aux_2021_2025.csv`
  - 국민여가활동조사 원자료에서 응답자 ID 기준으로 가구소득 관련 변수를 추출한 보조 테이블
  - 소득구간 파생변수 생성에 사용

- `preference_income_exp_model_performance.csv`, `preference_rank_weighted_model_performance.csv`
  - 선호모형 실험별 성능 비교 결과
  - 주요 지표: LogLoss, Top1 Accuracy, Top3 HitRate, Macro F1, Balanced Accuracy, Brier

## 전처리 방식
- 국민여가활동조사의 여가활동 코드를 문화누리 가맹점 중분류 기준으로 재분류함.
- 분석 대상 중분류와 직접 대응되지 않는 교통수단, 숙박, 여행사는 모델링 대상에서 제외함.
- 음악, 체육용품은 마이크로데이터 문항과 문화누리 가맹점 분류의 대응이 불안정해 선호 기반 ML 대상에서 제외함.
- 향후 희망 여가활동 1~3순위를 모델 타깃으로 사용함.
- 1순위, 2순위, 3순위에 각각 1.5, 1.25, 1.0의 순위가중치를 부여함.
- 응답자별 순위 응답을 long 형태로 변환하여 `응답자-중분류` 단위 학습 데이터를 생성함.
- 동일 응답자 안에서 같은 중분류가 반복되는 경우 해당 중분류의 순위가중치를 합산함.
- 입력변수는 성별, 연령대, 조사년도, 소득구간, 장애여부, 17개 시도를 중심으로 구성함.
- 소득은 가구소득 원자료를 기준으로 중위소득 50% 이하 여부와 다층 소득구간을 파생하여 실험함.
- 학습, 검증, 테스트 데이터는 응답자 단위로 분리하고, 연도와 타깃 분포가 섞이도록 stratified split을 적용함.

## 모델링 방식
- 모델링 목적은 격자별 문화누리 대상자의 시설분류별 잠재수요를 추정하기 위한 중분류 선호확률 산출임.
- H3SFCA 접근성 분석에는 각 분류별 확률값이 직접 수요항으로 사용되므로, 확률 예측 안정성을 우선 평가함.
- 주요 평가 기준은 LogLoss로 설정하고, Top1 Accuracy, Top3 HitRate, Macro F1, Balanced Accuracy를 보조지표로 확인함.
- 비교 모델은 다항로지스틱, class-weight 조정 로지스틱, Random Forest, Extra Trees, HistGradientBoosting, Rank-Ordered Logit, LightGBM LambdaRank, XGBoost Ranker, CatBoost Ranker를 사용함.
- 만족활동 기반 모델과 향후 희망활동 기반 모델을 모두 비교하되, 최종 H3SFCA 수요모형은 향후 희망활동 기반 모델을 우선함.

## 성능 테스트 과정
- 기본 실험: 성별, 연령대, 조사년도 중심 baseline 모델 성능을 확인함.
- 가중치 실험: 1~3순위 가중치 조합을 조정하여 선호 타깃의 안정성을 비교함.
- 소득 실험: 중위소득 50% 이하 이진구간과 다층 소득구간을 각각 추가하여 성능 변화를 확인함.
- 장애여부 및 시도 실험: 소득구간에 장애여부와 17개 시도 변수를 추가하여 최종 후보 모델을 비교함.
- 문화예술조사 파생변수 실험: 외부 문화예술활동조사 기반 파생변수를 추가했으나 성능 개선은 제한적이었음.
- 순위형 모델 실험: Rank-Ordered Logit과 LambdaRank 계열 모델을 적용했으나 최종 다항로지스틱보다 성능이 낮았음.

## 주요 성능 결과
- `base_sex_age + 다항로지스틱`
  - LogLoss 1.7148, Top1 0.3267, Top3 0.7370

- `income_band + HistGradientBoosting`
  - LogLoss 1.7103, Top1 0.3265, Top3 0.7365

- `income_band + 다항로지스틱`
  - LogLoss 1.7104, Top1 0.3235, Top3 0.7378

- `income_band_sido_disability + 다항로지스틱`
  - LogLoss 1.7011, Top1 0.3247, Top3 0.7352, Macro F1 0.1155, Balanced Accuracy 0.1428

- `income_band_sido_disability + HistGradientBoosting`
  - LogLoss 1.7013, Top1 0.3232, Top3 0.7385, Macro F1 0.1104, Balanced Accuracy 0.1401

- `income_band_sido_disability_economy + HistGradientBoosting`
  - LogLoss 1.7033, Top1 0.3317, Top3 0.7378

- `Rank-Ordered Logit`
  - LogLoss 1.7167, Top1 0.3148, Top3 0.7275

- `LightGBM LambdaRank`, `XGBoost Ranker`, `CatBoost Ranker`
  - LogLoss 1.819 이상으로 최종 후보에서 제외함.

## 최종 피쳐 및 모델 선정
- 최종 모델: 다항로지스틱
- 최종 타깃: 향후 희망 여가활동 1~3순위 기반 문화누리 중분류 선호확률
- 최종 피쳐:
  - 성별
  - 연령대
  - 조사년도
  - 소득구간
  - 장애여부
  - 17개 시도
  - 성별·연령 결합 특성

- 선정 근거:
  - 테스트셋에서 LogLoss가 가장 낮아 확률 예측 안정성이 가장 높음.
  - H3SFCA는 분류별 확률을 수요항에 직접 사용하므로 Top1 정확도보다 확률오차가 더 중요함.
  - HistGradientBoosting은 일부 Top1 성능이 높았으나 LogLoss가 더 크고 해석성이 낮아 최종 모델에서 제외함.
  - 순위형 모델은 자료 구조상 적합해 보였으나 실제 성능이 낮아 최종 모델에서 제외함.

## 활용 방식
- 최종 모델은 격자별 성별·연령별 문화누리 대상자 인구에 중분류별 선호확률을 부여하는 데 사용함.
- 격자별 잠재수요는 `성연령별 문화누리 대상자 인구수 × 중분류별 선호확률`로 계산함.
- 산출된 격자별·중분류별 잠재수요는 H3SFCA 접근성 분석의 수요항에 결합함.
- 이를 통해 단순 인구 기반 접근성이 아니라 선호 수요를 반영한 문화시설 접근성을 산출함.
